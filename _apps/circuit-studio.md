## Overview

Circuit Studio is a Tinkercad-style circuit designer and simulator for Arduino Uno and Nano projects. Place parts, snap wires between pins and run your Arduino code to see the circuit respond — fully offline.

## Key features

- **Arduino Uno and Nano** with snap-and-connect wiring, bendable ribbon cables and draggable wire ends.
- **Parts library** including perfboard, speaker, DFPlayer Mini, ILI9341 SPI display, 4×4 membrane keypad, male/female headers, ribbon jumpers, TP4056 and J5019 charging modules, toggle switch and 21700 Li-ion cell.
- **Runs Arduino IDE code**, including multi-file sketches (.ino and .h tabs).
- Labelled SVG parts, panning and zoom.
- Same Help menu as my other apps: user guide, packages, safety, privacy and About.

## Who it is for

Makers and scientists prototyping Arduino-based instruments who want to test wiring and code before building hardware.
