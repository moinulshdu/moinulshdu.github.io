Download & install

{% if page.status == "released" %}

The app is free and open source. Downloads, release notes and the full installation guide are on GitHub.

Download the latest release on GitHub →

  1. On the GitHub release page, under Assets, download the .zip file.
  2. Unzip it and move the folder somewhere permanent (for example Documents), not Downloads or a cloud-synced folder.
  3. Start the app by double-clicking the launcher: the .bat file on Windows, the .command file on macOS, or the .sh file on Linux.
  4. On first start the app checks for the Python packages it needs and asks before installing anything.

Needs Python 3. On macOS, unsigned apps may show a security warning the first time; the installation guide in the repository explains how to open it. Questions or bugs: open an issue on GitHub.
